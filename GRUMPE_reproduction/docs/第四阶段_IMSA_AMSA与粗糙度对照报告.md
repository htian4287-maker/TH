# 第四阶段：IMSA、AMSA 与宏观粗糙度严格对照

## 1. 目的

本阶段只改变反射模型，保持合成真值地形、六景照明/观测几何、初始 DEM、噪声强度、PHCL 参数及上一阶段确定的积分参数 `τ=0.01、σ=11 px` 不变。目标不是用合成数据宣称某模型对所有 NAC 区域都最好，而是验证：

1. IMSA 与 AMSA 的模型差异是否能传播到坡度、反照率和 DEM；
2. 错误模型能否被逐像元反照率吸收；
3. 固定月球平均宏观粗糙度 11° 与忽略粗糙度有何差异；
4. 选择模型时为什么不能只看最终 DEM RMSE。

## 2. 实现范围与公式来源

- Grumpe 论文 Eq. (17)–(20)：Hapke 总反射率、阴影隐藏冲日效应、DHG 与 Cornette–Shanks 相函数；
- IMSA：`M(μ0,μ)=H(μ0)H(μ)-1`；本阶段使用 Hapke 2002 level-2 H，避免把 H 函数近似精度混入 IMSA/AMSA 对照；
- AMSA：使用 Hapke 2002 的 Legendre 展开，计算 `P(μ0)`、`P(μ)` 与 `P̄`，阶数截断为15；
- 宏观粗糙度：使用 Hapke 1984 的有效余弦 `μ0e、μe` 和阴影因子 `S`；Grumpe 按 Warell (2004) 将月球平均粗糙度固定为11°。

Grumpe 两篇论文没有完整展开 AMSA 与粗糙度的辅助公式，因此这两部分属于为复现 Grumpe 系统而补入的 Hapke 原始模型，不应误写成 Grumpe 自创公式。

## 3. 数值测试

核心测试由10项增至14项，新增验证：

- DHG 的30阶 Legendre 重建与解析相函数一致；
- 当粒子相函数各向同性时，AMSA 严格退化为 level-2 IMSA；
- 粗糙度为0°时，`S=1、μ0e=μ0、μe=μ`；
- 对各向异性粒子，AMSA 与 IMSA 产生可测的反射率差异。

全部14项测试通过。

## 4. 实验矩阵

符号 `A→B` 表示使用 A 正演影像、使用 B 反演坡度和反照率。

| 实验 | 类型 | 作用 |
|---|---|---|
| IMSA11→IMSA11 | 匹配 | IMSA 基线 |
| AMSA11→AMSA11 | 匹配 | AMSA 基线 |
| AMSA11→IMSA11 | 多次散射失配 | 检验把 AMSA 数据当 IMSA |
| IMSA11→AMSA11 | 多次散射失配 | 检验把 IMSA 数据当 AMSA |
| AMSA11→AMSA0 | 粗糙度失配 | 真实11°但忽略粗糙度 |
| AMSA0→AMSA11 | 粗糙度失配 | 真实0°但错误假定11° |
| AMSA0→AMSA0 | 匹配 | 0°粗糙度控制组 |

前四组另使用随机种子44–48重复5次，共完成20次 PHCL＋论文松弛积分。

## 5. 五种子多次散射结果

下表为均值±样本标准差。

| 正演→反演 | DEM RMSE (m) | 坡度向量 RMSE | 反照率 RMSE | 反射率 RMSE |
|---|---:|---:|---:|---:|
| IMSA11→IMSA11 | 0.20424±0.00061 | 0.03792±0.00032 | 0.002378±0.000019 | 7.1675e-5±2.88e-7 |
| AMSA11→AMSA11 | 0.19851±0.00055 | 0.03674±0.00031 | 0.002154±0.000017 | 7.0116e-5±2.89e-7 |
| AMSA11→IMSA11 | 0.17808±0.00058 | 0.03629±0.00027 | 0.018390±0.000014 | 9.4054e-5±4.27e-7 |
| IMSA11→AMSA11 | 0.22697±0.00056 | 0.04148±0.00035 | 0.017184±0.000016 | 8.4272e-5±3.69e-7 |

成对结果：

- IMSA 真值被 AMSA 反演：5/5 次 DEM、坡度、反照率和反射率残差均变差；DEM RMSE 平均增加0.02273 m（约11.1%）。
- AMSA 真值被 IMSA 反演：5/5 次反照率和反射率残差变差，反照率 RMSE 增至匹配模型的约8.54倍，反射率 RMSE 增加约34.1%；但 DEM RMSE 反而平均降低0.02043 m。

后一现象不是“IMSA 正确”的证据。逐像元反照率和低通 DEM 先验共同补偿了错误模型，使这一个小尺度合成 DEM 的高度误差偶然下降，但代价是明显错误的物理反照率与更差的影像拟合。这正是反射模型—反照率—坡度不可辨识性的实例。

## 6. 粗糙度结果（种子44）

| 正演→反演 | DEM RMSE (m) | 坡度向量 RMSE | 反照率 RMSE | 反射率 RMSE |
|---|---:|---:|---:|---:|
| AMSA11→AMSA11 | 0.19809 | 0.03668 | 0.002159 | 7.0480e-5 |
| AMSA11→AMSA0 | 0.18532 | 0.03590 | 0.004263 | 7.7547e-5 |
| AMSA0→AMSA0 | 0.20115 | 0.03756 | 0.002149 | 7.0916e-5 |
| AMSA0→AMSA11 | 0.21497 | 0.03944 | 0.004564 | 7.4314e-5 |

错误增加11°粗糙度时，DEM RMSE 增加6.87%、反射率 RMSE 增加4.79%，反照率误差增至2.12倍。反向忽略真实11°时也出现 DEM RMSE 偶然降低，但反射率残差增加10.03%、反照率误差增至1.97倍。其含义与 AMSA→IMSA 的补偿现象相同。

## 7. 阶段结论

1. AMSA 与宏观粗糙度已从“待实现”推进为“实现并通过受控测试”。
2. 在模型匹配时，IMSA 和 AMSA 都能完成稳定重建；本组合成数据中 AMSA 匹配结果略优，但差异不足以证明 AMSA 对所有真实 NAC 数据普遍更好。
3. 模型失配会显著污染反照率并提高影像残差，但最终 DEM RMSE 可能因正则化补偿而偶然降低。
4. 后续真实 NAC 模型选择必须至少同时使用：留出影像反射率残差、跨景反照率一致性、外部 DEM/LOLA 高程检查和空间误差结构。只按训练区 DEM RMSE 或“图看起来更平滑”选模型是不可靠的。
5. 本阶段不是 Grumpe 论文 Table 1 的像元级数值复刻：地形尺度、相位角分布与 M³ 数据不同，不能要求得到18.6 m与53.7 m的原表数值。
