# 复现状态与边界

## 状态定义

- **已实现并测试**：具有独立数值测试或已知真值的合成验证。
- **论文目标等价、求解器不同**：优化目标与论文相同，但使用更稳定的现代数值求解器。
- **部分实现**：保留论文核心结构，但暂未包含全部物理修正或数据流程。
- **待实现**：当前不能把结果称为该部分的严格复现。

## 当前可以得出的结论

当前工程已经证明：

1. 在反射率模型正确、几何已知的合成多景数据上，可以联合恢复高分辨率坡度与逐像元反照率；
2. 只有无偏坡度时，Poisson 积分本来就可能最好；
3. 加入已声明的系统性坡度偏差后，低通绝对高程约束能显著压制大尺度漂移，同时比直接逐像元高程约束保留更多细节。
4. 参数权重和 Gaussian 宽度存在联合最优区间；过小的 τ 无法抑制漂移，过大的 τ 会迫使结果退回粗 DEM。
5. 反射模型失配会被逐像元反照率部分吸收；因此单看 DEM RMSE 可能出现“错误模型偶然更低”的假象，必须同时检查保留影像残差和反照率一致性。
6. 在真实 clean8 的7景训练、M119留一验证中，同等20次 PHCL 预算下，AMSA 的留出 RMSE 比 IMSA 低3.248%，相关系数高0.016166；这是支持 AMSA 的初步证据。
7. 扩展到clean8八折留一后，AMSA在6/8折胜出，平均RMSE比IMSA低0.951%，平均相关系数高0.00377；但Wilcoxon双侧检验p=0.25，尚无统计显著性，因此只能说存在AMSA略优趋势。
8. 从20次严格暖启动续算到60次后，16/16个训练目标继续下降，但IMSA仅1/8折、AMSA 0/8折的留出误差改善；平均留出RMSE分别恶化2.07%和1.55%，证明盲目增加迭代会过拟合。AMSA在60次时8/8折较低，说明其相对更稳健，但60次产品本身不优于20次。

当前不能得出的结论：

- 不能声称 AMSA 在所有 NAC 区域一定优于 IMSA；虽然已完成8折留一，但优势小且p=0.25，两组所有折都在20次PHCL上限结束、未达到自动收敛阈值；
- 不能把60次的显著AMSA优势解释成60次DEM更好；两模型的平均留出误差都比20次更差，60次仅用于过迭代诊断；
- 不能声称合成实验的参数就是月球 NAC 的最优参数；
- 不能仅凭一个输出 DEM 判断 Grumpe 方法优于 ASP；
- 不能把 ISIS/ASP 预处理步骤误称为 Grumpe 核心算法。
