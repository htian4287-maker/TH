# Wu 2016 SAfS：论文—代码映射与复现边界

## 论文算法映射

| 论文内容 | 本复现位置 | 说明 |
|---|---|---|
| 式 (1) `I=A·G(p,q)` | `model.py`、`solver.py` | 观测强度由曝光、相对反照率与 Lunar-Lambert 反射率相乘。 |
| 式 (2) 四角高程坡度 | `model.cell_slopes` | 适配北向上、行号向南增加的栅格符号。 |
| 式 (3) 低通法向约束 | `solver._node_costs` | 固定对齐的 2×2 子单元组取平均，与上一层上采样 DEM 的同组法向比较。 |
| 式 (4)–(8) 分块常量反照率 | `model.estimate_piecewise_albedo` | 在对数域分离强度与反射率低频项，避免直接求反照率倒数的不稳定性。 |
| 式 (9) 联合误差 | `solver._node_costs` | 四个邻接单元的光度残差加低通法向残差。 |
| 分辨率逐层翻倍 | `solver.pyramid_shapes` | 论文区域实际为 12×11 起始、1382×1262 结束，共 8 层。 |
| 光照方向松弛 | `solver._color_order` | 顺序模式为逐节点即时更新；全图模式使用四色互不相邻节点批次。 |
| Lunar-Lambert | `model.lunar_lambert_reflectance` | `G=2Lμ0/(μ0+μ)+(1-L)μ0`，L 通过独立 DTM 敏感性试验选择。 |
| 逐像元成像几何 | `scripts/run_nac_m173.py` | 从 ISIS 几何栈读取入射/发射角及太阳/航天器方位角并转为 ENU 向量。 |

## 论文没有给出的内容

作者没有公开源代码；论文也没有完整给出 Lunar-Lambert 相位系数、两项权重、反照率窗口、有限差分步长、每层迭代次数、收敛阈值和阴影阈值。因此本项目不能声称为作者程序的逐位复刻。处理原则是：

1. 缺失量全部显式配置，禁止隐藏在脚本常数中。
2. 先用已知真值的合成地形排除实现错误。
3. 再以 2 m 参数试验和独立官方 NAC 立体 DTM 选参。
4. 最后才运行论文 0.5 m 全分辨率区域。

## 与 GRUMPE 和 ASP 的核心差异

- SAfS：单景，联合优化形状和分块平滑反照率，Lunar-Lambert，层级局部松弛。
- 当前 GRUMPE 复现：Hapke + PHCL 估计梯度，再以低分辨率 DEM 约束积分；单景时逐像元反照率会吸收大部分亮度，结果几乎保持初始 DEM。
- ASP SfS：成熟工程求解器，可联合多景、相机修正、曝光和反照率等，但内部优化高度封装；本次单景设置产生更强高频变化和条纹。

三者不仅是“反射模型不同”，也是反照率参数化、正则化、优化变量、层级策略和软件成熟度不同。因此报告分别给出几何、坡度、亮度拟合和条纹指标，不用单一指标宣布普遍优胜。
